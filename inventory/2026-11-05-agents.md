## Migration coupling

Deleting an agent that is bound by a command is a two-file change: remove `agent:` from the
command frontmatter and add the skill trigger (or leave the command procedural). Current bindings:

```
HHRU/.kilo/command/{parse-vacancies,analyze-market,cleanup,park,match-candidates}.md
linear-tech/.kilo/command/{audit,scrape}.md
factory-ui-template/.kilo/command/test-auth.md   # agent: fullstack.md (invalid id)
```

## Rule

See ADR 0005: a custom agent must be selectable before tools run, need a different model or
permission profile, and be impossible to express as a skill. Otherwise it is a skill or is deleted.
